# AI 生成的小游戏

用浏览器打开对应目录里的 `index.html` 即可开始。

## 水果消消乐

`fruit-match3`

交换相邻水果，横竖三个及以上相同即消除。10×10 棋盘，六种水果，默认 30 步。炸弹和购物车会在旁边的水果被消除时发动。可自定义步数和特殊卡概率，也可开关音效。没有可消除的交换时会提示并自动洗牌。

详细规则和操作见 [fruit-match3/操作说明.md](fruit-match3/操作说明.md)。

## 扫雷

`minesweeper`

翻开所有不含雷的格子。格子上的数字表示周围八格里有几颗雷。左键翻开，右键在「标雷」和「问号」之间切换。某个数字周围的旗子数量和它相等时，可以左右键同时点这个数字，翻开其余格子。

默认初级：9×9，10 颗雷。外观可选经典、夜色、海洋。

详细规则和操作见 [minesweeper/操作说明.md](minesweeper/操作说明.md)。
